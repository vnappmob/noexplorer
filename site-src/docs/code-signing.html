Windows: free code signing provided by SignPath.io, certificate by SignPath Foundation. The application is in progress: until it's approved, Windows builds are not signed.

What is signed

Platform Signature
Windows The app (noexplorer.exe) and both installers (.exe, .msi), through SignPath.
macOS Apple Developer ID, notarized by Apple.
Auto-updates Every update is also signed with NoExplorer's own update key. Installed apps reject anything else.

Only NoExplorer's own code, built from this repository, is signed. Builds run on GitHub-hosted runners from a release tag (release.yml), so every signed file can be traced back to the source it was built from.

Team and roles

Role Members
Committers and reviewers Kris Luu (@ltdangkhoa)

Changes from other contributors are reviewed by a committer before they're merged. Each release is approved by an approver before it's signed. Team members use multi-factor authentication for GitHub and SignPath.

Privacy

NoExplorer doesn't send information to other networked systems unless you ask it to, except for the update check, which you can turn off. Details: Privacy.
