⇄ Two panes, one gesture

Drag left → right to upload, right → left to download. Drop on a folder or a breadcrumb to target it. You can also drop straight from Finder or Explorer.

⚡ Built for speed

Six files in parallel. Big files go up as multipart uploads with four parts in flight. Live progress, speed and cancel for every transfer.

📊 Folder sizes, live

Every folder on your computer shows its size and an ncdu-style bar as you browse. Scanned in the background, faster than ncdu, and kept up to date as files change.

👁 Quick look

Press Space to preview images, video, audio, PDF and text on either side, without downloading first.

🏠 Self-hosted friendly

Path-style requests are on by default. Point it at http://nas:9000 and it just works. No "advanced settings" hunt.

🛟 Safe by design

Never deletes or overwrites your local files. Collisions become name (1).ext, and partial downloads never look complete.

🔄 Updates itself, runs in the background

New versions install with one click, no reinstalling. Close the window and NoExplorer stays in the menu bar / tray, showing transfer progress and notifying you when it's done.

👥 All your servers

Add as many S3 accounts as you like and switch between them from the bucket pane.

🪶 Tiny & open source

About 10 MB, native on macOS, Windows and Linux. MIT licensed: read the code that handles your keys.

Up and running in a minute

  1. Download and open NoExplorer. Settings opens on first launch.
  2. Enter your endpoint (e.g. https://minio.example.com), access key and secret key. Leave Path-style requests on.
  3. Click Test, then Save. Pick a bucket and start dragging.

FAQ

Which servers does it work with?

Anything that speaks the S3 API: MinIO, SeaweedFS, Garage, Ceph RGW, Cloudflare R2, Backblaze B2, Wasabi and AWS S3. For AWS you can turn path-style off.

Where are my credentials stored?

Only on your computer, in the app's config folder, readable only by your user. Nothing is sent anywhere except to the endpoint you configure. The code is open: config.rs.

Windows says "Windows protected your PC"

Windows builds aren't code-signed yet. Click More info → Run anyway. The macOS build is signed and notarized by Apple.

Can I drag files from the app to my desktop?

Not yet. Drag them into the left pane (any folder on your computer), or select them and press F5.

My server uses a self-signed HTTPS certificate

That isn't supported yet. Use plain HTTP inside your LAN, or a trusted certificate (e.g. Let's Encrypt). It's on the roadmap.
