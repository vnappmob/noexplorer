Drag. Done.

Drag left → right to upload, right → left to download. Drop on a folder or a breadcrumb to target it, or drop straight from Finder or Explorer. Folders keep their structure.

  • 6 files in parallel; big files in parallel parts (S3 multipart, Nextcloud chunks, Box sessions)
  • Live speed, progress and cancel, with a beam showing where it's going
  • Keeps going in the menu bar / tray when you close the window

Folder sizes. Faster than ncdu.

Every folder on your computer shows its size as you browse, scanned in the background by our own parallel scanner and kept up to date as files change. A storage bar puts the folder against the whole disk, like macOS Storage settings.

  • One system call per batch of files on macOS (no stat per file)
  • Polite: low priority, stays on your disk, no surprise permission prompts
  • Going back to a folder is instant

Compare. Be sure.

After a backup, see exactly what's missing or different on each side. Contents are verified by checksum without downloading anything, and odd counts are explained (hello, .DS_Store). One click uploads or downloads the difference.

  • S3 ETags (including multipart uploads), Box SHA-1, Nextcloud checksums
  • Never calls a file "verified" unless the hash really matches

The details, done right

⌘K palette

Commands, accounts, buckets, places and files in one search box.

Every account, everywhere

Split the right side into up to 3 accounts and drag between them to copy cloud to cloud. Or switch from the menu bar / tray.

Secrets in your keychain

Keys and app passwords live in Keychain / Credential Manager, never in plain text and never in the UI.

Move to Trash, never delete

Local files only ever go to the real Trash / Recycle Bin. Downloads never overwrite: name (1).ext.

Live folder view

Files added or removed in Finder, or by a download, show up on their own.

Self-hosted friendly

Path-style S3 on by default. Point it at http://nas:9000 and it works.

Updates itself

Signed updates install in place with one click.

Smooth with huge folders

Virtualized lists stay fast with hundreds of thousands of files.

Connect in a minute

  1. Download and open NoExplorer. Settings opens on first launch.
  2. Pick your provider (AWS, R2, B2, Wasabi, DigitalOcean, or self-hosted MinIO / SeaweedFS…). The form tells you what to enter.
  3. Enter the endpoint (leave it empty for Amazon S3), access key and secret key. Keep Path-style on for self-hosted servers.
  4. Click Save & use, pick a bucket, start dragging.
  1. In Settings → Accounts, pick Nextcloud / ownCloud and enter your server address.
  2. Click Sign in with Nextcloud… and approve NoExplorer in your browser.
  3. That's it: NoExplorer gets its own app password, kept in your system keychain. No password typed into the app.
  1. In Settings → Accounts, pick WebDAV.
  2. Enter the full WebDAV folder URL from your server or NAS (Synology, QNAP, Apache, nginx…), your user name and password.
  3. Click Save & use.
  1. In the Box Developer Console: Create Platform App → Custom App → User Authentication (OAuth 2.0). An open-source app can't ship a secret, so you use your own (free) app.
  2. Set the Redirect URI to http://127.0.0.1:53682/callback and tick Read and write all files and folders.
  3. In NoExplorer pick Box, paste the Client ID and Client secret, and click Sign in with Box….

FAQ

Which services does it work with?

Anything that speaks the S3 API (AWS S3, Cloudflare R2, Backblaze B2, Wasabi, DigitalOcean Spaces, MinIO, SeaweedFS, Garage, Ceph RGW), Nextcloud and ownCloud, any WebDAV server or NAS, and Box (beta).

Where are my keys and passwords stored?

In your system's credential store: macOS Keychain, Windows Credential Manager, or Secret Service on Linux. They never reach the app's interface and are only sent to the server you configured. The code is open: secrets.rs.

Why does Box need my own app?

Box sign-in needs a client secret, and an open-source app can't keep one secret. Creating a free Custom App takes two minutes (see Setup → Box), and the tokens stay on your computer.

My file counts don't match after a backup

Open Compare (⌘K → Compare, or right-click a folder). It lists exactly what's missing or different and explains the usual suspects: system junk like .DS_Store and Thumbs.db is skipped on purpose, and symlinks aren't followed.

Can it delete or overwrite my local files?

No. Downloads never overwrite (they become name (1).ext), and removing local files only moves them to the Trash / Recycle Bin, where you can put them back.

Windows says "Windows protected your PC"

Windows builds aren't code-signed yet. Click More info → Run anyway. The macOS build is signed and notarized by Apple.

My server uses a self-signed HTTPS certificate

Not supported yet. Use plain HTTP inside your LAN, or a trusted certificate (e.g. Let's Encrypt). It's on the roadmap.
