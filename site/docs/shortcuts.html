Keyboard shortcuts

On Windows and Linux, use Ctrl where this page says ⌘.

Keys Action
Tab ← → Switch pane (Tab also goes through split remote views)
↑ ↓ (+ Shift) Move or extend the selection
Enter Open a folder. Remote file: preview. Local file: open in its app
Space Quick look
F5 or ⌘ ↵ Copy the selection to the other pane (upload or download)
⌫ or ⌘ ↑ Up one folder
⌘ ⌫ or Delete Remote: delete (asks first). This computer: Move to Trash
⌘ K Command palette: commands, accounts, buckets, places, files
⌘ L Type a path
⌘ \ Split the remote side (another account below)
⌘ W Close the remote view you're in
⌘ F Filter the current folder
⌘ R Refresh
⌘ , Settings
F2 · ⌘ Z Rename · undo the last rename, move or duplicate (experimental)
⌘ [ ⌘ ] Back / forward (experimental)
⌘ T · Ctrl Tab New tab · next tab (⌘W closes a tab) (experimental)
